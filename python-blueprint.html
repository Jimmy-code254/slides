Before we beginWhy Python?

A practical first language

Readable enough to start. Powerful enough to grow.

Why teams choose it

Clear syntax helps people focus on the problem. A broad library ecosystem supports quick prototypes and substantial production systems. Python also runs across the major desktop platforms.

Python is a tool, not a shortcut: strong software still needs design, testing, and care.
3 minutes. Ask learners what they associate with Python. Emphasize readability and ecosystem as practical reasons, not a promise that every task or team should use Python.

Setup / 01Install the interpreter

Choose your operating system

Install Python 3 from a trusted source

Windows

Download Python 3 from python.org. During setup, enable the option to add Python to PATH if shown.

Then install the Windows build of VS Code.

macOS

Install Python 3 from python.org or with Homebrew using brew install python3.

Then install the macOS build of VS Code.

Linux

Use your distribution's package manager. On Ubuntu, for example: sudo apt install python3.

Install the matching Linux build of VS Code.

Python is the interpreter that runs code. VS Code is the editor. The Microsoft Python extension connects the editor to an installed interpreter; it does not install Python itself.
8-12 minutes, hands-on. Pause and help learners choose the correct downloads. Linux installation differs by distribution; follow that distribution's package guidance. On managed computers, follow local IT policies.

01 / SyntaxStructure matters

Read the shape

Python statements usually run line by line. A colon begins a block, and indentation groups its lines. Names are case-sensitive.

score = 12
if score >= 10:
    print("Level up")
Challenge Change the score and predict when the message appears. What happens if the print line is not indented?

Reference: W3Schools / Python Syntax

6 minutes. Focus on the colon and indentation as syntax, not decoration. Ask learners to predict before running the example.
02 / OutputShow a result

Make a program speak

print() displays text, numbers, and values. Separate items with commas to print a message without needing string formatting.

topic = "Python"
print("We are learning", topic)
print(3 + 4)
Challenge Print your name and a number on separate lines, then print the result of adding two numbers.

Reference: W3Schools / Python Output

6 minutes. Explain that commas in print() separate values and Python adds a space. Contrast printed text with the result of a calculation.
03 / CommentsNotes for people

Explain intent

A comment starts with #. Python ignores it while running. Useful comments explain why something is done instead of restating the line.

# Save the workshop seat count
seats = 24
print("Seats:", seats)
Challenge Add a helpful comment above a variable that stores your favourite number. Confirm it does not appear in output.

Reference: W3Schools / Python Comments

5 minutes. The comment is visible in the editor but does not appear in output. Ask whether a comment that repeats the code helps the reader.
04 / VariablesName a value

Store and reuse

A variable is a name that refers to a value. Use clear names; assignment uses one equals sign.

student = "Amina"
age = 19
is_member = True

print(student)
print(age)
Challenge Create variables for a city and its population. Print both values and choose clear names.

Reference: W3Schools / Python Variables

6 minutes. Explain assignment with the equals sign: a name refers to a value. Ask learners to change the name and age and predict the output.
05 / Data typesValues have kinds

Start with four

str is text. int is a whole number. float is a decimal number. bool is True or False.

Use type() to inspect a value.

name = "Python"
learners = 30
rating = 4.5
ready = True

print(type(name))
print(type(learners))
Challenge Make one value of each type, then use type() to check them.

Reference: W3Schools / Python Data Types

6 minutes. Have learners classify each value before running the type() calls. More Python types exist; keep this first pass to four common ones.
06 / NumbersNumeric values

Whole or decimal?

int holds whole numbers, float holds decimal numbers, and complex represents numbers with an imaginary part. Start by recognising int and float.

apples = 8
price = 1.5

print(apples + 2)
print(price * 2)
print(type(apples))
print(type(price))
Challenge Set a quantity and a decimal price. Print the quantity plus one and the price multiplied by two.

Reference: W3Schools / Python Numbers

6 minutes. Use type() to show that 8 is int and 1.5 is float. Keep complex values as recognition only in this session.
07 / CastingConvert a value

Make conversion explicit

Use int(), float(), or str() to convert compatible values. Converting a float to int removes the decimal part; it does not round.

whole = int(6.8)
decimal = float("3.5")
label = str(12)

print(whole)
print(decimal)
print(label)
Challenge Convert "25" to an integer and add 5. Convert 4 to text and print it beside a short label.

Reference: W3Schools / Python Casting

7 minutes. int("25") works, but int("twenty-five") does not. Casting 6.8 to int gives 6 because the decimal part is removed.
